# Gabay frontend (React)

React + Vite + React Router + Bootstrap.

## Run
```
cd frontend
npm install
npm run dev
```
Open the address shown in the terminal (usually http://localhost:5173).

## Routes
| Path | Page |
|---|---|
| `/` | redirects to `/login` |
| `/login` | static login layout (no backend connection yet) |
| `/dashboard` | empty placeholder |

## Build check
```
npm run build
```
